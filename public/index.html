打开 GitHub Actions ↗

在 GitHub 仓库的 Settings → Secrets and variables → Actions 中设置 SERPAPI_KEY，之后运行 Research internship scan。不要在网页或公开仓库中填写密钥。

日期与真实性

只有带有明确时刻与时区的正式截止时间才显示实时倒计时。预计窗口结束日期仅用于排序和参考。官方岗位链接是检查入口，并非此处实时证明仍有空缺；每次申请前请以官方页面核验。

隐私

个人收藏、申请状态与手动添加内容只存储在当前浏览器。自动扫描的公共职位会被提交至公开 GitHub 仓库；请勿在公共数据中添加个人信息。

可用功能

本版没有启用 AI API、邮件提醒或跨设备同步。
